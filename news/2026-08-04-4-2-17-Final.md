We are happy to announce the release of netty 4.2.17.Final. This is a bug-fix and security release.

We strongly recommend upgrading to this version to get the following security fixes:

- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-fccg-mwvh-qqg4) : algorithm inefficiency in `io.netty:netty-handler`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-cc6x-ffm5-83wf) : improper NUL byte neutrolization in `io.netty:netty-codec-socks`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-c4c3-7fpv-j4q5) : SNI bypass in `io.netty:netty-handler`
- [CVE-2026-59902](https://github.com/netty/netty/security/advisories/GHSA-2qj4-mmr9-4v2f) : memory exhaustion in `io.netty:netty-transport-sctp`
- [CVE-2026-59903](https://github.com/netty/netty/security/advisories/GHSA-8c42-7qj2-3j46) : cache poisoning & info disclosure in `io.netty:netty-codec-http`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-43fm-7cxg-hf3j) : validation bypass in `io.netty:netty-codec-mqtt`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-p85m-gvr3-788c) : improper hostname verification in `io.netty:netty-handler`

Other significant changes are:

* AsciiString.cached(String) should sanitize the provided String [#17007](https://github.com/netty/netty/pull/17007)
* Fix AsciiString.cached(String) performance regression [#17074](https://github.com/netty/netty/pull/17074)
* SslHandler: Fix possible buffer leak when an OOME is thrown during allocation [#17059](https://github.com/netty/netty/pull/17059)
* Add HttpContentCompressor constructor with ability to specify desired `maxPipelineDepth` [#17068](https://github.com/netty/netty/pull/17068)
* IoUring: preserve `readPending` when rescheduling canceled reads [#17087](https://github.com/netty/netty/pull/17087)
* Reject negative `maxOrder` in PooledByteBufAllocator [#17093](https://github.com/netty/netty/pull/17093)
* Fix `AdaptiveByteBuf._setLongLE` calling checked `setLongLE` [#17098](https://github.com/netty/netty/pull/17098)
* Snappy: Guard decoder against invalid chunk lengths [#17099](https://github.com/netty/netty/pull/17099)
* Update to latest netty-tcnative release [#17056](https://github.com/netty/netty/pull/17056)
* Use safe decompressor in Lz4FrameDecoder [#17118](https://github.com/netty/netty/pull/17118)
* IoUring: add `SO_INQ` support for Unix domain sockets [#17127](https://github.com/netty/netty/pull/17127)
* fix(mqtt): drop UNSUBACK reason codes for MQTT 3.x encoding [#17117](https://github.com/netty/netty/pull/17117)
* Codec-compression: Add decompressor API [#16745](https://github.com/netty/netty/pull/16745)
* Codec-compression: Add Bzip2Decompressor [#17145](https://github.com/netty/netty/pull/17145)
* Fix buddy cache evicting chunks with live buffers [#17154](https://github.com/netty/netty/pull/17154)
* Codec-compression: Add Snappy frame decompressor [#17153](https://github.com/netty/netty/pull/17153)
* Codec-compression: Add zlib decompressors [#17155](https://github.com/netty/netty/pull/17155)
* Codec-compression: Add Zstd decompressor [#17152](https://github.com/netty/netty/pull/17152)
* Codec-compression: Add LZF decompressor [#17147](https://github.com/netty/netty/pull/17147)
* Codec-compression: Add BrotliDecompressor [#17146](https://github.com/netty/netty/pull/17146)
* Codec-compression: Add Lz4FrameDecompressor [#17148](https://github.com/netty/netty/pull/17148)
* `HttpObjectEncoder` / `DefaultHttp2FrameWriter`: fix buffer leak when a `Throwable` is thrown during header encoding [#17089](https://github.com/netty/netty/pull/17089)
* Fix direct memory OOM on low-core containers [#17166](https://github.com/netty/netty/pull/17166)
* IoUring: Fix the `recvmmsg` emulation [#17187](https://github.com/netty/netty/pull/17187)
* Avoid classloader leak via GlobalEventExecutor terminationFuture failure [#17140](https://github.com/netty/netty/pull/17140)
* BrotliEncoder: Prevent duplicate close scheduling [#17175](https://github.com/netty/netty/pull/17175)
* Fix JdkZlibDecompressor losing the tail of highly compressible streams [#17191](https://github.com/netty/netty/pull/17191)
* Update compress-lzf to 1.2.1 [#17194](https://github.com/netty/netty/pull/17194)
* Do not write WebSocket handshake response to the tail of the pipeline [#17192](https://github.com/netty/netty/pull/17192)
* `HttpServerCodec`: do not consume the method queue for 1xx interim responses [#17182](https://github.com/netty/netty/pull/17182)
* Weakly reference engines from the OpenSSL engine map [#17199](https://github.com/netty/netty/pull/17199)
* OpenSSL: Allow to obtain used named group via OpenSslSession [#17058](https://github.com/netty/netty/pull/17058)

For more details please see the [complete release notes](https://github.com/netty/netty/releases/tag/netty-4.2.17.Final).
